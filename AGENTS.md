# Lit RPG repository guidance

- Start with START-HERE.md and PROMPT.md. The owner's current request overrides repository defaults.
- This repository contains a reusable writing method and original examples, not the live canon of every story that uses it.
- Preserve simple common language and natural sentence variety. Do not equate readability with uniformly short sentences.
- Use PLAYBOOK.md's current step and appropriate references. Honor a request to work one step at a time; complete a fully authorized chapter or episode without routine approval interruptions.
- Treat source capsules as attributed advice, not verified science or universal genre law. Read source coverage before claiming to know a video. Caption reading is distinct from watching or listening.
- Preserve one authoritative project registry and canon. Mark proposed changes; trace approved retcons through dependent chapters, rules, and ledgers.
- Keep full future plans away from bounded drafting and simulated-reader contexts. Report simulated feedback honestly.
- Keep raw source downloads, transcripts, tool logs, account data, and private manuscripts out of this public repository. Publish original synthesis, original examples, and source links only.
- Do not copy a source's passages, examples, story, characters, or commercial course into the playbook. Source links remain the place to consult the originals.
- New local project work belongs on D: when supported. Do not modify unrelated stories, skills, memories, or host configuration.
- Research and writing do not by themselves authorize voice-generation spending, account changes, submission, or release. Reuse explicit authorization when it exists.
- After a repository edit, check affected relative links, reading order, step/template alignment, source attribution, and any numeric examples. Verify remote file content and commit after an authorized upload.
